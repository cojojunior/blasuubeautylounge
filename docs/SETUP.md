# 🚀 Setup & Installation Guide

This guide will walk you through setting up the Blasuu Beauty Lounge project on your local machine.

## 1. Prerequisites
Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)
- A [Supabase](https://supabase.com/) account
- A [Moolre](https://moolre.com/) merchant account
- A [Google Cloud](https://console.cloud.google.com/) account (for Calendar integration)
